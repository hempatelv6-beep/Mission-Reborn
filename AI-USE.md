# How we used AI

NASA Space Apps asks teams to explain how they used AI. Here is what happened on this project.

## What the team did

We chose the challenge, the 10 machines, the story, the NASA pages, and the features. Team members checked the machine cards against those pages, including names, dates, and quoted evidence. A different person checked each card. The team also wrote the final website text, decided what still needed checking, and reviewed the site.

## What AI helped with

- Claude helped draft research cards from NASA links the team provided. The prompt asked it to quote the source for each fact and mark missing information as unverified.
- Claude Code read the NASA pages already on our source list to find sentences for the home page fun facts, and stored each quote with its fact for the team to check.
- Claude helped shorten some sentences and explain science terms for readers aged 11–14.
- Claude Code helped write and fix `index.html`, `styles.css`, and `app.js`, and drafted several project documents.
- AI drafted quiz questions and the short story lines written in each machine's voice. These still need the review listed in [TODO_VERIFY.md](TODO_VERIFY.md).
- Claude Code helped download and resize the NASA images listed in [IMAGE_CREDITS.md](IMAGE_CREDITS.md). Claude Code also wrote the code that draws the planets and the background astronauts, asteroids and satellite (see [IMAGE_CREDITS.md](IMAGE_CREDITS.md)). No photos, recorded voices, or videos were generated by AI.

The browser's built-in read-aloud voice reads the site's text. It is not an AI-generated recording.

## How we checked the work

The team chose the sources; AI did not choose them. A fact should not appear on the site without support from a NASA page. Anything not checked yet belongs in [TODO_VERIFY.md](TODO_VERIFY.md). Quiz answers should already appear in the related machine text. The talking lines are story writing, not real quotes, and the site labels them that way for screen readers.
