# AI use

The Mission Reborn team chose the machines, NASA sources, and site features. Team members researched and checked the machine facts, edited the site text, and built the project. Open checks are listed in [TODO_VERIFY.md](TODO_VERIFY.md).

AI tools assisted with research drafts, some website code and copy, quiz questions, and fictional narration written in each machine's voice. Team members reviewed and revised this work. The site also offers synthetic read-aloud narration from ElevenLabs; it is not a NASA recording. See [AUDIO_CREDITS.md](AUDIO_CREDITS.md).
